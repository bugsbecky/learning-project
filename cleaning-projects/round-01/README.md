# Round 1 — 28 Sep 2026 through 11 Oct 2026, 12:00

Eight tasks. Three clean the sink, three clean the sink and the toilet, two clean the whole bathroom. Rules: [Rules](../rules.md). Setup and terminal I/O: [Getting started](../getting-started.md).

Submission Sundays at 12:00: **4 Oct 2026** and **11 Oct 2026**. After that, whatever was not accepted expires.

Order is free. Easy, then medium, then hard works best, because later tasks reuse words from the early ones (class, list, map, reading a line from the terminal).

If Java is still new, plan for the high end of the time range. Getting stuck is part of the task. The steps on each page are there so you are not stuck on "what is a class?".

Every Java task has more than one file. `Main.java` is the terminal. The other files are the logic. How that compiles, and why there is no `package` line yet, is in [Getting started](../getting-started.md). In Cursor, `/hint`, `/explain`, `/files`, `/run`, `/error`, `/review`, and `/check` will coach you and will not write the task.
