# Categories

Every round mixes these. Java stays the focus. Web and Linux are the short changes of pace, so it is not eight times the same console loop.

A task is only in a round when three things are true:

1. There is a **real-world problem** she can repeat in one sentence.
2. She learns **something that comes back** (a class, a map, a file, an exit code).
3. The must-list is **checkable**. Otherwise submission turns into an argument about taste.

| Category | What it is for | Typical size |
|----------|----------------|--------------|
| Java Core | Language, objects, collections, input, errors | One small console app |
| Puzzle | A known algorithm shape, wrapped in an everyday story | One function plus a few cases |
| Real-world tools | Files, formats, reports — how small real tools start | Several classes |
| Web snack | HTML, CSS, JS, just enough for one useful page | One page |
| Linux | Shell, files, networking, exit codes | One script |

## Example projects (not assigned)

Directions for later rounds, not tasks. Must-lists are written when the round is planned, from what [progress.md](progress.md) says.

**Java Core**

- Library: borrow and return books, with a due date and overdue titles.
- Playlist: songs, duration, "what still fits in 30 minutes?".
- Address book: search, sort, spot duplicate numbers.

**Puzzle**

- Two Sum as a receipt: which two items add up to the voucher?
- Bracket check for a chat message with broken markdown.
- Queue at a checkout: who is next, who skipped the line?

**Real-world tools**

- CSV budget book, later JSON, later an actual database.
- A month report as a text file you could send to someone.
- A small CLI with subcommands (`add`, `list`, `sum`).

**Web snack**

- A cleaning schedule that marks today.
- A weather tile that calls a public API and does not swallow errors.
- A shopping list in the browser that survives reload (`localStorage`).

**Linux**

- Healthcheck: ping, disk, exit code.
- The same check on `cron`, with a log file.
- "Which port is listening?" and "which process holds this file?".

## Left out of round 1 on purpose

No Spring, no Maven, no database, no required Git, no JUnit. Those come after classes, lists, and files feel normal. A framework is a bad excuse, and so is skipping the cleaning.
