# Code for Cleaning

Programming tasks traded for bathroom cleaning. She solves a task and can explain it. He cleans the agreed part.

Focus: **Java**, from a first real console program to classes, files, and a small parser. Short HTML/CSS/JS and Linux tasks in between. Every task is a real problem (passwords, a shared bill, a calendar, a server, a budget), not a toy exercise with no context.

**Current:** [Round 1](round-01/README.md) — 28 Sep 2026 through Sunday **11 Oct 2026, 12:00**.

## Read this order

1. [Rules](rules.md) — submission, the explain-check, cleaning, what "solved" means.
2. [Getting started](getting-started.md) — terminal, compile and run, several Java files without packages, how Java reads the keyboard, and the `/hint` commands.
3. [Categories](categories.md) — task types, and example projects for later rounds.
4. [Round 1](round-01/README.md) — the 8 tasks for these two weeks.
5. After each Sunday: fill in [progress](progress.md). The next round is written from that.

Solutions stay off git. Put code under `cleaning-projects/solutions/` (that folder is in `.gitignore`).

## Rhythm

Every 14 days there are 8 new tasks: 3 easy, 3 medium, 2 hard. Submission is Sunday at 12:00. Unsolved tasks expire. Missing concepts come back later.

Next time, bring: which tasks are solved, where she got stuck, what was fun, what should be repeated.
